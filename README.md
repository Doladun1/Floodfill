# Dynamic Maze Solver with Recursive Exploration:
Built a recursive, object oriented maze solving program that constructs and updates an internal map dynamically as new input is received. Program locates center of maze using Floodfill algorithm then resolves shortest path. A GUI visualizes the solving process. Solution can be adapted for a physical rover. Exploring new solving algorithms with AI techniques such as Q Learning and predictive modeling to improve decision making, and solver performance
